Business Analytics: de la pregunta de negocio a la decisión

Cuatro cursos encadenados con guía interactiva, manual científico y laboratorios en Python. Para pregrado, con profundizaciones para postgrado. Todos los casos son empresas ficticias con datos simulados.

Descargar todo (ZIP) Repositorio en GitHub

Cursos

Fundamentos de Business Analytics

Datos, decisiones, análisis visual y herramientas básicas. Profundización en probabilidad y modelos.

Laboratorios en Python

Descargue el repositorio y, desde su carpeta raíz, con Python 3.12:

python -m venv .venv
pip install -r requirements.txt
jupyter lab

Active el entorno antes de instalar (.venv\Scripts\activate en Windows; source .venv/bin/activate en macOS o Linux).
