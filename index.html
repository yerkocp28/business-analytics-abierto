Business Analytics: de la pregunta de negocio a la decisión

Cuatro cursos encadenados con guía interactiva, manual científico y laboratorios en Python. Para pregrado, con profundizaciones para postgrado. Todos los casos son empresas ficticias con datos simulados.

Descargar todo (ZIP) Repositorio en GitHub

Elige por dónde empezar

Primera aproximación: Fundamentos → Estadística → Modelos Predictivos → Analítica Estratégica. Si ya dominas un tema, revisa el objetivo y el criterio de logro de cada módulo antes de avanzar.

Para estudiar: anticipa, ejecuta, cambia una condición y explica. Para preparar clases: cada ruta conecta la guía, el fundamento científico y el laboratorio; distingue el núcleo de la profundización.

Laboratorios en Python

La guía y sus simuladores funcionan en el navegador, también sin conexión. Los controles de los notebooks necesitan Jupyter y un kernel de Python: descarga la colección completa para disponer de sus datos y funciones.

Descargue el repositorio y, desde su carpeta raíz, con Python 3.12:

  1. python -m venv .venv
  2. Activa el entorno con el comando correspondiente a tu sistema.
  3. python -m pip install -r requirements.txt
  4. jupyter lab

Active el entorno antes de instalar (.venv\Scripts\activate en Windows; source .venv/bin/activate en macOS o Linux).
